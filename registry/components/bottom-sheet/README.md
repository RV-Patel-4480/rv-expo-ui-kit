# BottomSheet

A scaffolded component for a bottom sheet implementation. (Currently in development).

## Installation

```bash
npx rv-expo-ui add bottom-sheet
```

## Usage

```tsx
import { BottomSheet } from "@/components/ui/BottomSheet";
import { Text } from "react-native";

export function Example() {
  return (
    <BottomSheet>
      <Text>Bottom sheet content</Text>
    </BottomSheet>
  );
}
```
